## Conduit v0.2.44

### macOS: stay signed in after updates

Updating Conduit on a Mac used to log you out of D&D Beyond and Roll20: each new version asked for
access to its saved-login key again, as if it were a different app. From this version on, Mac builds keep
the same identity from one update to the next, so your logins carry over — like Chrome.

- **This update** asks for Keychain access one last time: choose **Always Allow**. If you're signed out
  this once, sign in again and it will stick.
- Windows and Linux are unaffected — their logins already survived updates.
