## Conduit v0.2.5

Name syncing between poke5e and Roll20.

### What changed

- **poke5e → Roll20 name sync.** poke5e is the source of truth for character names. When you
  **Bind Token** a poke5e Pokémon to a Roll20 token whose name differs, Conduit offers to push the
  poke5e name into Roll20 — renaming **both** the token (so HP-by-name matching stays aligned) and
  the **character it represents** (which is what Roll20 uses for the chat speaker). This fixes rolls
  showing a stale/mismatched name like `004 - Charmander` when your sheet says otherwise.
- **Confirms each time**, and only touches tokens/characters you control (GM: all). No-ops when the
  names already match.

Set a Pokémon's nickname in poke5e to your preferred name, bind its token, and confirm — the token,
its character, and the chat attribution all unify on the poke5e name.
