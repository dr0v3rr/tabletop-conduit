## Conduit v0.2.32

Pokémon now show their type matchup — weaknesses, resistances, and immunities — in the Defenses block, on screen and on the printable sheet.

### What changed

- **Type-matchup defenses for poke5e.** Select a Pokémon and the Defenses block now lists its
  **Weak** (×4 / ×2), **Resist** (×½ / ×¼), and **Immune** (×0) types, derived from its own type(s) via
  the type chart — each as a type-colored chip. It uses the same chip language as the D&D Beyond
  resist/immune/vulnerable block, so both systems read the same way, and it pairs with the damage math
  Conduit already applies (a hit that's halved or doubled now shows *why*).
- **On the printable sheet too.** The exported PDF gains a **Defenses** section — the Pokémon's type
  matchup, or a D&D Beyond character's damage resistances/immunities/vulnerabilities.

Behind the scenes: a new tested `typeMatchup()` on the existing type chart, reused by both the sheet and
the PDF; D&D Beyond defenses are unchanged. Reviewed for injection/regression before shipping. Tests:
395 passing.
