## Conduit v0.2.34

Security update: ships a patched Electron runtime.

### What changed

- **Electron updated 43.4.1 → 43.7.7.** Fixes a high-severity advisory (sandboxed preload code-cache
  poisoning by a compromised renderer) — relevant because Conduit loads remote pages (Roll20, D&D
  Beyond, poke5e) in its panes. Same major version, so no behaviour change; the app was boot-tested on
  the new runtime.
- **Dependency audit cleaned up.** Resolved the remaining runtime-adjacent advisories via `npm audit
  fix` (14 → 8 findings; the Electron runtime is now clean). The 8 that remain are all inside the
  `electron-builder` build toolchain — dev-only, never shipped in the app, and left as-is because their
  only fix is a breaking toolchain change that would risk the release pipeline for no user-facing gain.

No application code changed. Tests: 395 passing.
