## Conduit v0.2.38

A dependency-security fix. No app behavior changes.

### What changed

- **Cleared the `sprintf-js` advisory (CVE-2026-97058 / GHSA-hp3w-g68c-fv3c).** The build toolchain
  (`electron-builder`) was dragging in a deep, deprecated chain — `@electron/get@3 → global-agent →
  roarr@2 → sprintf-js@1.1.3` — and `sprintf-js` has no patched release. Pinning `@electron/get` up to
  **v5** (the version Electron itself already uses) drops `global-agent` entirely, severing the chain.
  `npm audit` now reports **0 vulnerabilities**, and ~50 stale transitive packages are gone.

The vulnerable package was **build-time only** (never shipped in the app that runs on your machine), so
this had no runtime impact — but the tree is now clean. Verified with a full macOS/Windows/Linux build
(Electron still downloads and packages correctly under `@electron/get@5`). Tests: 411 passing.
