## Conduit v0.2.33

Corrects Pokémon type effectiveness to poke5e's rules: capped at ×2 / ×½ / ×0 — no ×4 or ×¼.

### What changed

- **Type effectiveness is now capped (poke5e-correct).** poke5e uses D&D-style
  resistance/vulnerability — per [its rules](https://poke5e.app/rules/damage-types), *"there is no
  'double vulnerability' or 'double resistance' due to dual types."* Earlier releases used the
  video-game stacking rule (×4 / ×¼). Now a Pokémon is **Vulnerable ×2**, **Resistant ×½**,
  **Immune ×0**, or **Normal ×1** — never ×4 or ×¼ — and a type that's super-effective on one half of a
  dual type but resisted on the other cancels to normal. This affects both the damage Conduit applies
  and the type-matchup shown in the Defenses block (on screen and on the printable sheet).
  - Example: Snom (Ice/Bug) is now **Vulnerable to Fire ×2** (was ×4); Ralts (Psychic/Fairy) **Resists
    Fighting ×½** (was ×¼) and is **Immune to Dragon**.

Matches poke5e's own client (which buckets by vulnerability / resistance / immunity and applies the
capped multiplier). Tests: 395 passing.
