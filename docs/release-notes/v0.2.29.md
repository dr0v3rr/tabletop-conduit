## Conduit v0.2.29

Read move/ability details on hover, Pokédex move text wraps, and pasted note images can be resized.

### What changed

- **Hover for full details.** Hover a move, spell, or weapon on the character sheet to read its full
  wording (plus a quick meta line — type, casting, range, PP) right there, without pushing it to
  Roll20 first. Pokédex moves get the same card, which also shows the action cost, range, duration,
  PP, and how the move scales at higher levels.
- **Pokédex move text wraps.** Long move descriptions in the Pokédex were clipped to a single line;
  each move now shows its full text, wrapped, under a clean header line.
- **Resize note images.** Pasted or captured images are downscaled to keep notes small, which can
  leave them hard to read. Click an image in a note to get resize handles on its right edge — drag to
  make it as large (or small) as you like. The aspect ratio is kept, and the size sticks across saves
  and restarts.

Behind the scenes: this release was reviewed by an adversarial security/correctness pass before
shipping. The note sanitizer now keeps a validated numeric image width (no styles, units, or
expressions) so resized images persist safely; two hover/resize edge cases found in review were fixed.
Tests: 387 passing.
