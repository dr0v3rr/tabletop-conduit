## Conduit v0.2.25

Put images and formatting into your campaign Notebook — screenshots, a one-click Roll20 grab, and markdown shortcuts.

### What changed

- **Images in notes.** Paste any image straight into a Notebook page — an OS screenshot, or
  right-click → "Copy Image" in Roll20. Images are downscaled and embedded inline, so they render
  immediately and travel with the note.
- **📷 Capture Roll20.** A new toolbar button in the Notebook grabs the live Roll20 view and drops
  it into the current page — no need to reach for a screenshot tool.
- **Markdown shortcuts.** Type markdown and it formats as you go: `# ` / `## ` / `### ` for headings,
  `- ` and `1. ` for lists, `> ` for a quote, `---` + Enter for a divider, and inline `**bold**`,
  `_italic_`, and `` `code` ``.
- **Note content is sanitized (security).** Anything pasted into a note is cleaned to a safe subset
  before it's stored or shown — scripts, event handlers, embedded frames/forms, and remote images or
  CSS that would "phone home" are stripped, so a copied-from-the-web note can't track you or run code.
  Pasted images are re-encoded, which also discards any embedded payload.

No data-format changes — existing notebooks, archives, stats, and settings carry over. Tests: 376
passing (adds notebook markdown-shortcut and sanitizer suites).
