## Conduit v0.2.4

Resilience update for the poke5e integration.

### What changed

- **Auto-detects the poke5e API key + endpoint at runtime.** poke5e's public anon key was
  previously hard-coded, so a key rotation — or an endpoint move — would silently break Pokémon
  sheets. Conduit now reads the key the live poke5e site sends on its own API calls and uses that,
  falling back to a baked-in default only until detection happens. The detected value is cached and
  re-applied on the next launch.
- **Handles poke5e's endpoint move.** poke5e migrated from the raw Supabase host to the custom
  domain `api.poke5e.app`; that's now the default, and either endpoint is detected automatically.
- **Safe by construction.** A detected key is adopted only if it's a well-formed Supabase JWT whose
  role is exactly `anon` (a leaked `service_role` or malformed token is refused), and only if it
  comes from a trusted host (`*.poke5e.app` / `*.supabase.co`) — so nothing can repoint the app at
  a hostile server or escalate its privileges.

No engine changes. 220 passing tests (adds coverage for the credential detection/validation).
