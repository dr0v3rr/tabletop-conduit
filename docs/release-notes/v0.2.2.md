## Conduit v0.2.2

First release under the **Conduit** name — a single-window desktop companion that puts your
character sheet next to your virtual tabletop and sends properly-formatted rolls into it.

**Sources:** D&D Beyond · poke5e (Pokémon 5e) · SRD/Open5e + D&D Beyond monsters
**Virtual tabletop:** Roll20

### Downloads

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `Conduit-0.2.2-arm64.dmg` / `Conduit-0.2.2-arm64-mac.zip` |
| Windows x64 | `Conduit Setup 0.2.2.exe` (installer) / `Conduit 0.2.2.exe` (portable) |
| Linux x64 | `Conduit-0.2.2.AppImage` |
| Linux arm64 | `Conduit-0.2.2-arm64.AppImage` |

Checksums are in `SHA256SUMS`. macOS is Apple-Silicon only for this build (Intel via Rosetta
from the `.zip`, or build a universal binary from source).

### Install & first launch

Builds are **unsigned**, so you'll see a one-time OS warning:
- **macOS:** right-click **Conduit** → **Open** → **Open**.
- **Windows:** SmartScreen → **More info** → **Run anyway**.
- **Linux:** `chmod +x Conduit-0.2.2*.AppImage && ./Conduit-0.2.2*.AppImage`.

See [`docs/RELEASES.md`](../RELEASES.md) for full details, verification, and build instructions.

### Notes

- Rebrand from the internal "DDB-Roll20 Companion" — same engine, same behavior.
- Rules engine validated by 212 unit tests, including a golden test pinned against D&D Beyond's
  own computed sheet numbers.
- Packaged app is hardened via Electron fuses (`afterPack`).
