## Conduit v0.2.8

Display any move, spell, feat, or item's wording on the Roll20 table.

### What changed

- **📖 Display in VTT.** Every actionable "thing" that carries descriptive text now has a compact
  **📖** button next to it. Click it and Conduit posts that thing's full wording to the Roll20 chat
  as a clean info card — titled with its name, a details sub-line (type · range · PP, etc.), and the
  text — attributed to your active character and **visible to the whole table**. No more paraphrasing
  "what does this move do?" from memory. Wired into:
  - **Moves & Spells** — e.g. Hypnosis → *"The target must make a WIS save … falling asleep on a failure."*
  - **Weapons / attacks**
  - **Feats & abilities** (trainer path features, Pokémon abilities)
  - **Inventory items**
- **Move wording plumbed through.** poke5e move descriptions (and range/type) now reach the sheet,
  including the handful of moves whose text contains structured tables (Fling, Acupressure, …),
  which are flattened to readable prose. D&D Beyond spell and weapon descriptions are carried through
  too.
- **Untrusted-text hardening.** All displayed wording is scraped/API text, so the card builder
  (`displayCard`) strips HTML, decodes entities, and — crucially — removes `{`/`}` so no description
  can break out of or forge the Roll20 `{{ … }}` template. Length-capped, and it uses the universal
  `default` template so every game renders it regardless of sheet.

No engine or data-format changes — existing archives and stats carry over. Tests: 240 passing
(adds a card-sanitizer suite and move-wording coverage).
