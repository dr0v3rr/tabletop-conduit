## Conduit v0.2.17

The character-sheet PDF now always fits on a single page.

### What changed

- **PDF scales to fit one page.** The exported sheet is now scaled down uniformly so the whole thing —
  abilities, saving throws, skills, passives, attacks, spells/moves, features, equipment, and notes —
  always lands on **one page**, regardless of how much a given character has. Previously long sheets
  spilled over and, because of how print pagination splits a two-column layout, blocks like Skills or
  Passive could end up alone on a second page. That no longer happens.
- **Hardened PDF rendering (security).** The print page now carries a strict Content-Security-Policy
  with a per-render nonce: only Conduit's own layout script can run, inline event handlers are
  blocked, and no external resources can load. Combined with the existing full HTML-escaping of every
  character-supplied value (names, features, equipment, spells/moves, image), this ensures nothing
  from a character sheet can execute as markup or script when the PDF is generated.

Internal: the release pipeline now creates the GitHub release and uploads each asset sequentially
(reliable against GitHub's intermittent multi-asset upload errors). No data-format changes.
Tests: 295 passing (adds scale-to-fit and CSP/escaping coverage).
