## Conduit v0.2.26

Trainer money in the bag, item names back, and trainer sync repaired after poke5e's API changes.

### What changed

- **Trainer money (₽).** The Inventory section now shows your trainer's money, and — when you own the
  trainer — lets you edit it. Changes sync straight to poke5e (the same value shown in poke5e's own
  Inventory tab).
- **Item names fixed.** poke5e moved its item catalogue (`/items.json` → `/data/items.json`), which had
  turned every standard bag item into "(unnamed item)". Conduit now reads the new location, and no
  longer caches an empty catalogue on a hiccup, so item names are back.
- **Trainer sync repaired.** poke5e changed its `update_trainer` API — Conduit's trainer write (HP, and
  now money) was silently failing against the old signature. Conduit now matches poke5e's current
  full-row format exactly, so writing back to your trainer works again.

Behind the scenes: a full audit of every poke5e write endpoint confirmed the rest (Pokémon HP/status/
EXP, moves, inventory items, add/remove Pokémon) still match. No data-format changes on our side —
existing trainers, archives, and settings carry over. Tests: 376 passing.
