## Conduit v0.2.39

### Initiative → turn order, automatically

Rolling initiative now adds the result straight into Roll20's **turn order**, so you don't have to
switch to the VTT and type it in by hand.

- Hit **⚡ Init** for a poke5e trainer or Pokémon (or a D&D Beyond character) — Conduit rolls initiative
  as usual, reads the result back, and writes that exact value into the Roll20 initiative tracker.
- If the character is **bound to a token** (the ⚔ control), the roll attaches to that token's turn;
  otherwise it adds a row labelled with the character's name. Re-rolling **updates** the existing entry
  rather than adding a duplicate.

Note: writing the Roll20 turn order is a shared, player-editable operation, but it hasn't yet been
confirmed against a live game from a non-GM browser — if an entry doesn't appear, it'll be switched to
Roll20's native `&{tracker}` roll flag (which needs a token selected). Everything else is unchanged.
