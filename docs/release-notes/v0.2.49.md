## Conduit v0.2.49

### Add several items at once

**＋ Add item** on a poke5e trainer's bag now picks several items in one go: eight kinds of berry is one
trip, not eight.

- Tick items to select them. Each ticked item gets − / + to set how many to add.
- Filter by type (Berry, Medicine, Poké Ball…), search, **Select all in view** and **Clear**.
- Items you already hold show "in bag ×N", and adding more stacks onto that row.
- The footer shows what's selected ("4 items selected · 7 total") and one **Add 4 items** button.
- Added items get a **new** or **+N** badge in the bag for a minute.
- Roll20 gets **one card for the whole batch**, grouped by type.
- If some items don't save, the picker stays open with them still ticked and says which failed, so you
  can retry. The rest are added.

Held items on a Pokémon still add one at a time, as before.

### Pokécentre

**🏥 Pokécentre** in the Rest menu heals the trainer's whole team to full HP and saves it to poke5e.
Unlike a long rest it doesn't restore PP or cure status. On a trainer you can only view, it heals the
Pokémon on screen. A card is posted to Roll20.
