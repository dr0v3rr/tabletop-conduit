## Conduit v0.2.22

Multi-hit moves now roll all their attacks, with mechanically-correct STAB.

### What changed

- **Multi-hit moves roll every attack (poke5e).** Moves whose text says "Make two/three/four/five
  attacks" — Bubble, Double Kick, Bonemerang, Scale Shot, Dragon Darts, Surging Strikes and the rest
  (19 in all) — now post **one attack + damage card per hit** instead of a single card. The count is
  read from the move's wording; the "roll a d4 to keep hitting" moves (Fury Attack, Bullet Seed…) are
  left as a single roll on purpose, since their extra hits are conditional. The move list shows a **×N**
  tag, and clicking still spends **1 PP** for the whole move.
- **STAB is applied once per target — accurately.** Same-Type Attack Bonus is a once-per-target,
  first-instance bonus, and the app can't know how you'll split a multi-hit move across tokens, so it
  auto-applies STAB to the **first hit only** and strips it from the rest (keeping every per-hit bonus
  like the ability MOVE mod, Steelworker, or the Melee Master feat). It never assumes STAB on later
  hits.
- **A prominent reminder banner.** When a multi-hit move is used, a highlighted banner explains how
  STAB was applied: *"counts once — first hit only"* for a single-target move, or, for a **multi-target**
  move (Dragon Darts, Zing Zap, Twineedle, Dual Chop, Gear Grind, Precipice Blades), *"you can split
  these across different targets — add STAB to the first hit on each other target you strike."* It
  auto-dismisses and can be closed.

No data-format changes — existing archives, stats, and settings carry over. Tests: 330 passing (adds
multi-attack parse, STAB-once-per-target, and roll fan-out suites).
