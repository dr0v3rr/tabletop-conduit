## Conduit v0.2.36

Quality-of-life improvements for rolling and for poke5e play, plus a new Poké Ball throw animation.

### What changed

- **Advantage/disadvantage shows both dice.** On the universal roll template (used by poke5e), an
  advantage or disadvantage roll now posts *each* d20 as its own line with a note on which is kept
  (highest/lowest), instead of only the single kept die — so the table can see both results. Super
  advantage/disadvantage shows all three. The D&D 5e sheet template already showed both natively.

- **Damage-type dropdown is alphabetical.** When applying damage to a Pokémon, the type list is now
  sorted A–Z (both the poke5e and D&D type lists), so the one you want is where you expect it.

- **Money add / subtract.** The poke5e money control gained an amount field with **＋ Add** and
  **− Subtract** buttons (mirroring the damage/heal pattern), so you no longer have to compute the new
  total by hand — type an amount and adjust. The direct "set total" field is still there.

- **Double Team no longer rolls.** Its description mentions a reactive d4 (the duplicate-image
  mechanic), which was being mistaken for a use-time die. Using it now simply announces to the VTT and
  spends PP, with a rule reminder — no spurious roll.

- **Per-ball art in the bag.** Every Poké Ball in the inventory now shows its own art inline, and the
  catch window previews the selected ball — so you can tell Great / Ultra / Dusk / Quick / … apart at a
  glance. The art is drawn as recolorable vectors (20 ball types), keyed to the same ids the catch
  maths already uses.

- **Throw animation.** Throwing a ball — from the bag, the catch window, or the Pokédex "Catch…"
  shortcut — now plays a full-window animation of *that* ball: it arcs in spinning, flashes, drops with
  a bounce, and wobbles. It rests on the cliffhanger and never shows a result, because whether the
  catch holds is the GM's call. Honors "reduced motion."

Pure logic stays unit-tested; this release adds coverage for the ball art. Tests: 409 passing.
