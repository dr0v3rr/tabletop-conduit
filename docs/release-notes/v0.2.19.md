## Conduit v0.2.19

Trainer specialisations now boost their Pokémon's skill checks.

### What changed

- **Specialisation skill bonus applied to Pokémon.** A poke5e trainer's specialisation grants
  "+1 to all skill checks made by any of your `<type>`-type Pokémon" (per stack, summed across the
  Pokémon's types). Conduit previously only *showed* this on the trainer sheet — now it's actually
  added to the Pokémon's skill checks (and, through them, passive skills). It applies to **skill
  checks only** — never to saving throws, attack rolls, or raw ability checks. Skill rows show a
  tooltip ("Includes +N from the trainer's specialisation") when it's in play.

  The trainer's own specialisation effect (the ability-score bump or skill proficiency) is unchanged —
  it's already baked into the trainer's stored stats, so it isn't double-counted. Mappings are aligned
  with poke5e's current (2024) edition.

All poke5e changes are scoped to poke5e sheets and do not affect D&D Beyond characters. No
data-format changes. Tests: 311 passing (adds a specialisation suite: reading counts, per-type sum,
dual-type stacking, off-type = none, saves unaffected).
