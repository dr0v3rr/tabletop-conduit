## Conduit v0.2.3 — security update

Maintenance release focused on the runtime and toolchain. **Recommended for all users** — it
replaces the Electron/Chromium runtime that ships inside the app.

### What changed

- **Electron 33 → 43.4.1.** The app embeds live D&D Beyond and Roll20 web pages, so the bundled
  Chromium is security-relevant; this pulls in current Chromium/Electron patches.
- **Hardened right-click menu.** Our own UI panes now use a controlled, minimal context menu
  (Copy/Cut/Paste/Select-All, link actions, spellcheck fixes). "Inspect Element" is available only
  in development builds — packaged apps can no longer open DevTools on the renderer. The Roll20/DDB
  panes keep their own native site menus untouched.
- **Build/test toolchain bumped** (electron-builder 26, vitest 4, esbuild 0.28). These are
  developer-only dependencies and never ship in the app.
- **`npm audit`: 0 vulnerabilities** (was 19 across the dependency tree; 53 Dependabot alerts).
  Note the app has **no runtime npm dependencies** — every previous alert was build/test tooling
  except the Electron runtime itself, which this release updates.

No functional changes to the rules engine — still 212 passing tests including the golden test.
