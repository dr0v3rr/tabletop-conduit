## Conduit v0.2.13

Pokémon ability descriptions now show up on the sheet.

### What changed

- **Ability text is fixed.** A loaded Pokémon's passive abilities showed only a bare, lowercased id
  (e.g. `synchronize`) with no description. The abilities reference was being fetched from the wrong
  place — `/abilities.json` (a 404) read with an `abilities` key — so the lookup was always empty and
  every ability fell back to its raw id. It now loads from `/data/abilities.json` (an `items` array),
  so abilities render with their proper name and full text (e.g. **Synchronize** — "If this Pokémon
  becomes burned, paralyzed, or poisoned, its attacker receives the negative status condition as
  well…"). `resolveAbilities` also falls back to any name/description carried on the row, so a missing
  reference can never blank an ability out again.

This has been present since the first release; the Pokédex was unaffected (it reads ability text
embedded in the species data), which is why it only showed on the per-Pokémon sheet.

No data-format changes. Tests: 275 passing (adds an ability-text resolution suite).
