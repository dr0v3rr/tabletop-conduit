## Conduit v0.2.40

### Fixed: D&D Beyond rolls posting blank messages in some games

In a Roll20 game that doesn't use the D&D 5e character sheet (for example a Pokémon campaign), a D&D
Beyond character's attacks, spells and checks could arrive in chat as an **empty message**. Conduit
checks whether a game has the 5e roll templates, and that check was fooled by Roll20's own built-in
roll cards already in the chat history. It now looks for the 5e templates by name, so those games get
Roll20's universal card, which always renders.

### A tidier sheet

- **One header row** — the status line is now a small message at the bottom of the sheet that fades on
  its own (click to dismiss). Notebook is the 📓 icon.
- **⋯ next to the character name** holds the character actions: Reload, Export PDF, Bind HP to a token,
  Restore PP and Show keys, with Remove and Delete set apart at the bottom.
- **One 🌙 Rest button** replaces the three separate sets of rest buttons. On D&D Beyond it shows your
  Hit Dice to spend, then Short rest / Long rest; poke5e keeps its own rest rules.
- **The roll bar stays on screen** — Adv/Dis, the ± modifier, Crit, Whisper, Initiative, Reroll and
  search stick under the header while you scroll.
- **Hit Points fits on one row** (Temp HP moved into the section header).
- **Most-used sections first**: Attacks, Spells, Skills, Saves, Abilities, then Features and Items.
- **Session Log**: its eight buttons are now **Sync ▾** and **Export ▾** menus.
- Buttons use sentence case throughout.

Note: the Spells section's old "Rest" button (slots only) is gone; **Long rest** restores slots along
with HP and Hit Dice. Ethers/Elixirs (PP only) are still under ⋯ → Restore PP.

### Other fixes

- **Duplicate weapons** — two separate inventory entries for the same weapon (e.g. two daggers) now
  show as a single attack. Copies that roll differently (a +1 dagger and a plain one) stay separate.
- **Tooltips show clean text** — attack, spell, item and move descriptions from D&D Beyond no longer show
  raw HTML tags.
