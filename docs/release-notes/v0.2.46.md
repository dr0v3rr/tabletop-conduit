## Conduit v0.2.46

### No more blank rolls in Roll20

Roll20 draws each chat card with a **roll template**, and those come from the game's character sheet: a
D&D 5e game has the D&D cards Conduit uses, a Pokémon game doesn't. A card naming a template the game
lacks shows up **empty**. Conduit now makes sure that can't happen:

- **Checked on every roll**, not just when a character loads — switching the Roll20 pane to another game
  is picked up (an Eldritch Blast cast in a poke5e game after loading the character in a D&D game came
  out blank).
- **D&D cards only when the game has both** that Conduit uses; otherwise Roll20's universal card, which
  every game has.
- **A final safety net:** after posting a D&D card, Conduit reads the new chat message back. If it came
  out empty — or nothing appeared — the same roll is re-posted on the universal card, and that game uses
  the universal card from then on.
- Death saves and "Uses …" announcements get the same checks.

Tests: 472 passing.
