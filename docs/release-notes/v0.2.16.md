## Conduit v0.2.16

Export a printable character sheet as a PDF, and a small conditions-picker fix.

### What changed

- **Export a character sheet to PDF.** A new **📄 PDF** button in the character header renders the
  loaded sheet as a printable, D&D-Beyond-style page and saves it wherever you choose. The layout has
  the ability-score boxes, saving throws, skills (with proficiency/expertise), passives, and combat
  line down the page, plus Attacks, Spells / Moves, Features & Traits, and Equipment.
  - **Pokémon art** is shown on the left and embedded directly into the PDF, so the file is
    self-contained (no broken image if you open it offline). Non-Pokémon sheets simply omit it.
  - **Blank writing space**: the Equipment box has spare ruled lines to add gear by hand, and a
    **Notes** section (12 ruled lines) sits under Equipment for anything else.
  - Works for D&D Beyond characters and poke5e trainers; Pokémon and monsters export too (using the
    same layout). It's generated with Electron's `printToPDF` from a self-contained HTML page.
- **Conditions picker closes on select.** Choosing a condition now dismisses the dropdown, matching
  the poke5e status list — previously the D&D-condition picker stayed open after each pick.

No data-format changes. Tests: 292 passing (adds a printable-sheet DTO + HTML-render suite).
