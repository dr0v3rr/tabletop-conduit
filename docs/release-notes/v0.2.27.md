## Conduit v0.2.27

Added Pokémon get their types set correctly, rests restore PP, Pokémon damage types are covered, and advantage/disadvantage rolls are clearly labelled.

### What changed

- **Added Pokémon now load on poke5e.** poke5e's `add_pokemon` doesn't accept a type, so a Pokémon
  added through Conduit was left with an empty type — which poke5e's own trainer page couldn't render
  (it would spin/crash). Conduit now sets the species' types immediately after adding, so newly-added
  Pokémon open and delete normally on poke5e.
- **Long / Short rest.** New 🌙 Long rest and 🌗 Short rest buttons sit next to Initiative. A Long rest
  restores HP **and** all move PP and clears status; a Short rest is announced for shared tracking.
- **Pokémon damage types.** The damage-type picker is now source-aware: on a poke5e sheet it lists the
  18 Pokémon types (Bug, Rock, Fairy, …) instead of the D&D set. Damage dealt to a Pokémon applies the
  standard type-effectiveness multiplier against its defending type(s) — super-effective, not-very-
  effective, and immunities all stack for dual types.
- **Advantage/disadvantage is labelled.** poke5e's default roll card shows a single total, so a
  keep-highest/keep-lowest roll looked like an ordinary one. The roll field is now labelled
  "Roll (Advantage — keep highest)" / "(Disadvantage — keep lowest)" so it's unmistakable.
- **Simpler Pokédex catch.** "Catch…" in the Pokédex now just rolls the catch, the same as throwing a
  Poké Ball from the bag — no extra prompts.

Behind the scenes: a new tested Pokémon type-effectiveness chart, plus an audit confirming the
`add_pokemon`/`update_pokemon`/`update_trainer` signatures all match poke5e's current API. Tests: 381
passing.
