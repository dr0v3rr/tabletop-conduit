## Conduit v0.2.51

### TMs in the poke5e bag

poke5e now lets trainers carry TMs as items (256 of them, e.g. "TM 001 - Work Up"). Conduit read item
names from a list that didn't include them, so a TM in the bag showed as "(unnamed item)" and couldn't
be added from Conduit.

- TMs in the bag now show their name, type and description.
- The ＋ Add item picker has a **TMs** filter (after the other types), so you can tick and add TMs in
  bulk like any other item.
- If poke5e's TM list can't be reached, everything else still loads and TMs are picked up next time.

### Item picker

The picker used to stop at 200 rows without saying so. It now shows up to 300, and says "Showing 300
of N — search or pick a type to see the rest" when there are more.

### poke5e compatibility

Reviewed every poke5e change since 8 October. Nothing Conduit relies on broke: poke5e's two database
updates only add new bulk-fetch calls. The compatibility check now also covers the TM list and the
full trainer/Pokémon save calls (HP, EXP, status, money) without needing a trainer link.

Tests: 481 passing.
